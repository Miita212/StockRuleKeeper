# fixed-6-hk 학습 데이터 (hyeonkyeong, 2026-11-09)

[fixed-5-hk](../data_fixed5_hk/README.md)에 **yappang 검증(11/09)**에서 나온 지적과, 그 답으로 제안한 표현 기준을 반영한 데이터다.
기준은 하나다: **말뜻이 지표 하나로 정해지면 값 되묻기, 정말 두 가지로 읽히면 지표 모호 되묻기.**

다시 만들기: `python3 -I -X utf8 members/hyeonkyeong/data_fixed6_hk/build_fixed6_hk.py` (몇 초, 해시가 `SHA256SUMS_fixed6_hk.txt`와 같아야 함)

## 2. 바뀐 것 (한 턴 대화만, fixed-5-hk와 같음)

### 2.1 일반 문구 88개 정리 (D)

"어떤 기준으로 볼까요? 아래에서 골라 주세요."는 지표 모호 1,230개 가운데 88개였다. 한 줄씩 읽어 보니 문구만이 아니라 **정답이 틀린 줄이 많았다.** 그래서 문구만 바꾸지 않고, 사용자 말마다 처리를 정했다(`build_fixed6_hk.py`의 `GENERIC` 표).

| 처리 | 건수 | 예 |
|---|---|---|
| 값 되묻기로 고침 | 24 | "매출이익률이 높은 기업" 모호[5,6,7] → 매출순이익률, "영업이익이 증가하는 기업도 많아" 모호[8,9] → 영업이익 증가율, "자본잠식 위험에 처한 기업" 모호[4,5,6] → 자본잠식률 |
| 주제어 문구로 바꿈(후보는 검토 후 유지·수정) | 33 | "성과가 점점 좋아지는 기업" → "성장은 두 가지로…", "재무상황이 건전한 기업" 후보 [5,7] → [1,2,3,4] |
| 지움 | 31 | 지표와 관계없는 말("마지막 기회를 잃은 상태", "지지선을 넘어서는 주식들"), 매수·전망 질문("저평가된 상태라면 매수할 수 있을까요"), 영어 문장 5개 |

여러 턴 대화의 같은 문구 7개(영역 고르기 단계 등)는 뒤 턴과 엮여 있어 그대로 두었다.

### 2.2 표현 기준 (G1~G7)

| 규칙 | 표현 | 전 → 후 | train | val |
|---|---|---|---|---|
| G1 | 이익이 늘어나는 / 매출이 늘어나는 | 모호[8,9] → 이익만 말하면 영업이익 증가율(9), 매출만 말하면 매출액 증가율(8) 값 되묻기. 실적·성장·성과는 [8,9] 유지 | 2 | |
| G2 | 폭락·급락·푹 꺼진·많이 빠진 | 고점을 말하면 52주 고점 대비(16) 값 되묻기, 그냥 하락이면 모호[15,16] | 3 | |
| G3 | 규모·크기·몸집 큰 | 모호[14,19] → 시가총액(14) 값 되묻기. "덩치가 커지는"처럼 성장을 말하면 그대로 | 7 | |
| G4 | 가성비·가격 매력·가격 대비 | 모호[10,11,16] → [10,11] ("싸다" R1과 같게) | 2 | 1 |
| G5 | 저점·바닥·최저 | 모호[16,17]·[15,17] → 52주 저점 대비(17) 값 되묻기 | 54 | 1 |
| G6 | 잘 버는·장사 잘하는·벌이 | 모호[5,6,7] → [5,7]. 꾸준히·매년·항상·연속·안정·지속 등이 있으면 [5,6,7] 유지 | 54 | 2 |
| G7 | 본업 (늘어남 말 없음) | 영업이익(5) 값 되묻기 | 2 | |

출렁·요동·롤러코스터는 학습이 이미 변동성(18) 값 되묻기라 바꾼 게 없다(시험 쪽만 수정 제안).

이유:
- **G1** 매출은 이익이 아니다. 이익만 말했는데 매출액 증가율을 후보에 둘 근거가 없다.
- **G2** "급락"은 최근 기간 하락(15)과 고점 대비 하락(16) 둘 다 자연스럽다. 한쪽으로 정하면 다른 뜻으로 말한 사용자가 원하는 조건을 못 고른다. 고점을 말하면 16 하나다.
- **G3** 회사 규모는 보통 시가총액이다. 거래대금(19)은 "거래가 활발한"이 따로 맡는다.
- **G4** 가성비는 "가격에 비해 싸다"는 뜻이다. 52주 고점 대비는 하락폭이지 싼지가 아니다.
- **G5** "저점"은 17번 이름에 그대로 들어 있다. 같은 말이 세 가지 정답으로 섞여 있던 게 가장 나빴다.
- **G6** 배당 규칙 R3(많이 → 배당수익률, 꾸준히 → 연속 배당)와 같은 방식이다. 연속 영업흑자 연수(6)는 "꾸준히"를 말할 때만 후보에 든다.
- **G7** 회계상 본업 이익 = 영업이익이다. 늘어남을 말하면 영업이익 증가율(9) 그대로 둔다.

### 2.3 보강 47개 (AUG6, `aug_sentences6.py`)

위 기준의 대조쌍이다. 예: "고점에서 반 토막 난 종목"(16) / "주가가 곤두박질친 종목"(모호[15,16]), "대형주 위주로 보고 싶어"(14) / "하루에 거래가 많이 되는 주식"(19), "본업으로 잘 버는 회사"(5) / "버는 돈이 점점 많아지는 회사"(9).
- 시험(test_set·holdout)과 유사도 **0.65 이상**이면 뺐다. fixed-5-hk(0.75)보다 엄격하게 했다. 5개가 빠졌다(목록은 report).

### 2.4 holdout N019 교체

"순자산보다 싸게 팔리는 주식"이 학습 "회사 순자산보다 싸게 거래되는 주식"과 거의 같아(yappang 지적, 유사도 0.74) **"청산하면 지금 주가보다 더 받을 수 있는 회사"**(PBR 값 되묻기)로 바꿨다.

**알아 둘 점**: 학습 전체와 비교하면 holdout 30개 중 14개가 학습 문장과 유사도 0.65 이상이다(대부분 "PER 12배 미만 종목 찾아줘"처럼 숫자가 든 추출 문장). fixed-5-hk에서는 학습과 **같은 문장**만 검사했다. holdout 점수는 "처음 보는 문장" 점수로 읽으면 안 된다. 목록은 `report_fixed6_hk.json`.

## 4. 반영하지 않은 것

- `name`·`explain_*` 채우기: v6 추출 정답도 대부분 비어 있고, 앱은 `name`이 없으면 "내 원칙"으로 표시한다. 새로 만들면 라벨 잡음과 출력 길이만 는다.
- 현금 보유·배당 성장률·MACD 거절 문장: test_set에서 틀린 개념이라 학습에 넣으면 시험 점수만 부푼다.
- yappang 개선안 B(지표 이름이 들어간 모호 문장): 초안(`fixed5-draft.md`)을 받으면 이 기준과 맞는 것만 더한다.
- 여러 턴 대화: 뒤 턴이 앞 정답에 맞춰져 있어 그대로 두었다(예: "덩치 큰 회사" 7턴, "고점 대비 많이 떨어진 종목" 7턴).
