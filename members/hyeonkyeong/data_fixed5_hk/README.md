# fixed-5-hk 학습 데이터 (hyeonkyeong, 2026-11-09)

yappang **fixed-4**(8B·4B 공용 최종 통합본)를 바탕으로 라벨을 고치고 보강 문장을 더한 데이터다.
8B·4B를 이 데이터로 다시 학습해서 **새 4B / 새 8B / 8B v6(지금 앱)** 세 모델을 비교하려고 만들었다.
왜 고쳤는지는 [8B_v6_vs_fixed4_공유요약.md](../docs/8B_v6_vs_fixed4_공유요약.md)와 [yappang 채점 기준 비교](../docs/8B_v6_vs_fixed4_yappang채점기준_비교.md)에 있다.

## 2. fixed-4에서 바뀐 것

| 규칙 | 내용 | 건수 |
|---|---|---|
| **A** | 추출 답에 `anchors`가 없으면 `source`가 user·inferred인 지표 id로 채움 | **400** |
| **R1** | "싸다"류 지표 모호 후보를 **[PER, PBR]**로 통일. 원래 [PER, PBR, 52주 고점 대비]와 섞여 있었음. 메시지: "싸다고 볼 수 있는 기준이 두 가지예요. 어떤 걸로 볼까요?" | 66 |
| R1 | "자산 대비 싸다" → PBR 값 되묻기 | 1 |
| **R2** | "남기는/남는/마진" 지표 모호 [영업이익, 매출순이익률] → **매출순이익률 값 되묻기** | 13 |
| **R3** | "배당 많이/두둑/넉넉/쏠쏠" 지표 모호 [배당수익률, 연속 배당] → **배당수익률 값 되묻기** | 5 |
| AUG-REF | 20개 밖 개념 거절 보강. 30개 개념 × 3문장 | 90 |
| AUG-CON | 값 되묻기 / 지표 모호 경계 보강 (싸다·자산 대비·이익 대비·남는 이익·배당) | 33 |

- 학습 7,065 = fixed-4 6,942 + 보강 123. 지운 대화는 없다.
- R1~R3는 **한 턴 대화만** 바꿨다. 여러 턴 대화 3개는 뒤 턴이 앞 후보에 맞춰져 있어서 그대로 두었다(CSV에 "미변경"으로 남김).
- 응답 분포(train, 마지막 답 기준): 추출·수정 3,144 / 값 되묻기 1,400 / 지표 모호 1,230 / 거절 629 / 기간 되묻기 63 / 용어 설명 599
- 검사: 형식 오류 0, 추출 답 지표 20개, `anchors` = 사용자 지정 지표 id(남은 누락 0)

### 2.1 기준 (hyeonkyeong이 정함, 팀에서 바꿀 수 있음)

- **A `anchors`**: v6의 추출 답 2,095개가 모두 "`anchors` = `source`가 user·inferred인 지표 id" 규칙을 따른다. 이 규칙을 그대로 썼다.
- **R1 싸다 = [PER, PBR]**: 52주 고점 대비는 "싸다"가 아니라 "고점에서 얼마나 내려왔나"라서 뺐다. test_set "싸게 거래되는 주식"의 정답도 [10, 11]이다.
  - "가성비 / 가격 매력 / 가격 대비"는 test_set 정답이 [10, 11, 16]이라 이 규칙에서 뺐다(바꾸지 않음).
  - 자산·이익을 둘 다 말하면 [PER, PBR]에 둔다.
- **R2 남는 이익 = 매출순이익률**: fixed-4 안에서 "이익이 많이 남는 회사"는 이미 매출순이익률 값 되묻기 23개였다. 외부 LLM·템플릿으로 들어온 [영업이익, 매출순이익률] 13개만 달랐다. test_set "남는 장사하는 회사가 좋아", "이익이 두둑이 남는 회사"도 매출순이익률 값 되묻기다.
  - "이자 내고도 남는"(이자보상)은 제외했다.
- **R3 배당 많이 = 배당수익률**: fixed-4 안에서 "배당수익률 높은 / 고배당" 28개가 이미 배당수익률 값 되묻기였다. 외부 LLM으로 들어온 5개만 모호였다.
  - "꾸준히 / 연속 / 해마다"가 들어가면 제외했다(연속 배당 연수).
  - "배당주"처럼 양을 말하지 않으면 그대로 모호[12, 13]로 둔다.
- **부등호는 고치지 않았다.** fixed-4의 단일 지표 문장 1,213개가 "이상 `>=`, 이하 `<=`, 초과·넘는 `>`, 미만 `<`" 규칙과 맞는다(제외 문장은 뒤집어서 판단). 규칙과 어긋나 보인 38개도 열어 보니 모두 맞는 라벨이었다.
  - v6와 달랐던 71개(예: 영업이익 "0억 이상" `>=`)는 fixed-4 쪽이 맞다.

### 2.2 보강 문장 기준

- 직접 작성했다(`aug_sentences.py`).
- 거절 개념은 기존 학습 데이터의 거절 개념 50개, test_set 개념과 겹치지 않게 골랐다(감사의견, 유상증자, 전환사채, 볼린저밴드, 지수 편입 등).
- 숫자가 들어간 문장을 섞었다(예: "전환사채 잔액이 100억 넘는 곳 제외"). 숫자가 있으면 지표로 바꿔 버리는 오답이 있어서다.
- 거절 메시지는 기존 형식 그대로다: "X는 아직 쓰지 않는 지표예요. A이나 B로 볼 수 있어요."
- 필터: 기존 학습 문장과 같으면 뺐다. test_set·새 시험 문장과 유사도 0.75 이상이면 뺐다(띄어쓰기·문장부호를 빼고 비교). 해찬 `gen_aug_v6.py`와 같은 방식이다. 이번에 빠진 문장은 0개다.

## 3. 새 시험 세트 `holdout_new_hk.jsonl` (30문장)

- **학습에 넣지 않았다.** 데이터를 고치면서 test_set을 계속 봤기 때문에, test_set 점수는 좋게 나오기 쉽다. 그래서 이번 수정에 쓰지 않은 문장으로 마지막 비교를 하려고 만들었다.
- 구성: 추출 12, 값 되묻기 8, 지표 모호 3, 거절 7 (20개 밖 5, 추천 1, 예측 1)
- 학습 데이터와 같은 문장 0개, test_set과 유사도 0.75 이상 0개
- 팀원 사이에 기준이 갈리는 문장(규모·거래 활발·빚 많은)은 넣지 않았다.
- 형식은 test_set과 같다(`test_id`, `source=holdout_hk`, `kind`, `text`, `messages`, `output`). `eval_model.py --data`, `eval_q4b.py`의 `EVAL_FILES`에 그대로 넣을 수 있다.

## 4. 학습 방법

- 8B (haechan `train_qlora.py`)
  ```bash
  python -X utf8 train_qlora.py --model Qwen3-8B --out runs/qwen3-8b-fixed5hk \
    --train train_fixed5_hk.jsonl --val val_fixed5_hk.jsonl --epochs 3 --batch 2 --accum 8 --eval-steps 0 --keep-ckpts 10
  ```
  - 4090 24GB에서 batch 4×4는 메모리 부족 → 2×8
  - 7,065 + 여러 턴 → 에폭당 약 469스텝, 3에폭 약 2.5시간
- 4B (yappang `scripts/train_qlora.py`): `--train <이 폴더>/train_fixed5_hk.jsonl --val <이 폴더>/val_fixed5_hk.jsonl --out outputs/q4b-v5hk`

## 5. 비교 방법 (새 4B / 새 8B / 8B v6)

1. test_set 234 (정답 수정 후)와 `holdout_new_hk.jsonl` 30 **두 세트 모두**로 평가한다.
2. 채점은 두 가지를 같이 낸다.
   - yappang 기준(`eval_q4b.py`): JSON 유효율, 형태 일치, 필드 정확도, 은어 변환, 완전 일치
   - 구조 일치: 거절 여부 / 되묻기 이유 + 대상 지표 id / 추출 지표 + anchors. 정의는 [yappang 채점 기준 비교](../docs/8B_v6_vs_fixed4_yappang채점기준_비교.md) 6장
3. 체크포인트는 val loss가 아니라 **2·3에폭을 모두 평가해서** 고른다. fixed-4에서 val loss가 가장 낮은 3에폭이 2에폭보다 점수가 낮았다.

## 6. 바꾸지 않은 것 (팀에서 기준을 정해야 함)

학습 데이터와 test_set 정답이 서로 다르거나, 데이터 안에서 갈리는 표현들이다. 뜻만으로는 한쪽으로 정하기 어려워서 그대로 두었다.

| 표현 | 학습 데이터 | test_set 정답 |
|---|---|---|
| 규모가 큰 / 크기가 큰 / 몸집 큰 | 모호[14, 19] (yappang 통일) | "크기가 큰" 모호[14, 19], "몸집 큰" 값 14 (시험 안에서도 갈림) |
| 폭락 / 급락 / 푹 꺼진 / 와르르 | 모호[15, 16] 18개 | 기간 되묻기[15] |
| 저점 / 바닥 | 모호[16, 17] 36, 값 17 31, 모호[15, 17] 19 | "저점에서 아직 안 오른" 값 17 |
| 이익이 늘어나는 | 값 9 (영업이익 증가율) 56 | 모호[8, 9] |
| 출렁 / 요동 / 롤러코스터 | 값 18 14 | 모호[16, 18] |
| 장사 잘하는 / 본업이 잘되는 | 모호[5, 7] 9, 모호[5, 6, 7] 9 | "잘 버는" 모호[5, 6, 7], "본업 수익이 넉넉한" 값 5 |
| 가성비 / 가격 매력 | 없음 | 모호[10, 11, 16] (R1 싸다 [10, 11]와 다름) |

- 이 표현들은 네 모델(8B v6, 8B fixed-4 2·3에폭, 4B v4)이 **똑같이** test_set 정답과 다르게 답했다. 모델 문제라기보다 기준 차이로 보인다.
- 기준을 정하면 `build_fixed5_hk.py`에 규칙을 더해 다시 만들면 된다.
