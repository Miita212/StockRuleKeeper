- 웹 검색으로는 **금융위원회 금융용어사전의 정확한 데이터셋 주소와 이용허락범위를 확인하지 못했다.**
- 비슷한 서비스로 한국예탁결제원 "금융용어조회서비스"(data.go.kr/data/15001156)가 있다. 무료, 용어명 검색, 용어 설명 응답. 검색 결과에서는 이용허락범위 칸이 비어 있었다. 금융위 용어사전과 같은 자료인지는 확인하지 못했다.
- 계획표(yappang)에는 "파일(PDF)과 조회 API 등록, 일부 용어만 포함, API 응답에 HTML 태그가 섞임"이라고 적혀 있다 (검색 근거는 yappang 쪽).

## 직접 확인할 것 (사람이 포털에서)
- [ ] data.go.kr에서 "금융위원회 금융용어사전"을 검색해 데이터셋 주소 기록
- [ ] **이용허락범위** (상업적 이용·재배포·변경 가능 여부) 기록
- [ ] API 활용신청 방법과 승인 시간, 하루 호출 제한
- [ ] 마스터 정의에 쓰는 용어(지표 20개)가 사전에 있는지: 부채비율, 차입금의존도, 이자보상배율, 자본잠식, 영업이익, 순이익률, PER, PBR, 배당수익률, 시가총액, 변동성 등

## 정제 방법
1. 받은 결과를 `용어`, `설명` 두 칸 CSV로 저장 (예: `fsc_raw.csv`). **원본은 커밋하지 않는다.**
2. `python -I -X utf8 scripts/clean_glossary.py fsc_raw.csv` 실행 → `glossary_fsc.csv` 생성.
3. 정제 규칙: `<br>`·`</p>`는 줄바꿈, 나머지 태그 삭제, `&nbsp;` 같은 HTML 기호 변환, 공백 정리.
