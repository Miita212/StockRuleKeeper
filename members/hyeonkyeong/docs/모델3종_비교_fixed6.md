# 모델 3종 비교: fixed-6 8B / fixed-6 4B / v6 8B (hyeonkyeong, 2026-11-10)

> **한 줄 요약**: 같은 264문항, 원래 정답 기준으로 구조 일치는 **fixed-6 8B 87.9% > v6 8B 86.4% > fixed-6 4B 82.2%**.
> fixed-6 8B는 추출과 거절이 가장 좋고, v6는 되묻기가 가장 좋다. 4B는 같은 데이터·설정으로 학습해도 8B보다 5.7%p 낮다.
> 최종 모델은 앱 테스트(`모델3종_앱테스트.md`)까지 보고 고른다. 이 문서는 시험 점수 비교다.

- 시험 264문항 = 팀 test_set 234 (official111·haechan58·haechan31·haechan34) + 새 시험 30 (holdout_hk, 학습에 안 씀)

  - 제안 정답: 표현 기준이 다른 9문항을 fixed-6 기준으로 고친 것 (`data_fixed6_hk/test_fixed6_hk.jsonl`). fixed-6에 유리할 수 있어 참고로만 본다.

  - **구조 일치**: 거절이면 거절 여부만, 되묻기면 이유(`reason`)+대상 지표 id 집합, 추출이면 20개 지표(id·부등호·값·단위)+`anchors`가 같으면 맞음. 문구(`message`) 차이는 보지 않는다.

## 4. 읽는 법

1. **fixed-6 8B와 v6 8B의 차이는 작다**(원래 정답 264 중 4문항). 하지만 어디서 나는지가 다르다.
   - fixed-6 8B가 나은 곳: **거절 +4문항**(93.3 vs 84.4), **추출 +5문항**(96.1 vs 92.8), 처음 보는 문장(haechan58·31, 새 시험 30).
   - v6가 나은 곳: **되묻기 +5문항**(73.1 vs 65.7), official111.
2. **fixed-6의 되묻기 감점은 대부분 "기준이 다른 표현"에서 난다.** 아래 5장 9문항에서 fixed-6 두 모델은 모두 fixed-6 기준대로 답했고, 원래 정답과는 9개 모두 다르다(v6는 3개 맞음). 같은 계열의 문항(T104 "최근 주가가 많이 내린", T192 "수익 탄탄한", T194 "가격 대비 효율", T233 "와르르 무너진")도 같은 이유로 틀렸다. 그래서 제안 정답으로 채점하면 되묻기가 79.1%로 v6(74.6%)보다 높다.
3. **4B는 데이터를 같게 해도 8B에 못 미친다.** 차이는 추출(-10문항)과 거절(-5문항)에서 난다.
   - 추출: 부등호 방향("밑도는", "못 미치는", "안 되는") 실수가 많고(T220·T223·T224·T225·T226), "영업이익 1조 넘는 회사"(T011)를 0억 초과로 바꾸는 식의 값 실수도 있다.
   - 거절: "제일 좋은 거 하나 골라줘" 같은 **종목 추천 요청을 거절하지 않고 되묻는다**(T036·T135·T137). 앱 취지("추천은 하지 않는다")와 바로 부딪히는 실수다.
   - 새 시험 30에서는 8B와 같은 90.0%지만, 30문항이라 1문항이 3.3%p다.
4. **fixed-6 8B에서 새로 생긴 약점**: "영업이익이 흑자인 회사만 보여줘"(T009), "영업리익 흑자인 회사만"(T022)을 추출(영업이익 0억 초과)하지 않고 "어느 정도 이상 벌어야 괜찮을까요?"라고 값을 되묻는다. v6·4B는 맞게 추출한다. "본업 = 영업이익 값 되묻기" 보강(G7·대조 문장)이 "흑자"까지 번진 것으로 보인다(해석). 앱에서 자주 쓸 문장이라 앱 테스트에서 따로 확인한다.

## 8. 해석 주의

- **새 시험 30은 "처음 보는 문장"이 아니다.** 30개 중 14개가 학습 문장과 유사도 0.65 이상이다(대부분 숫자가 든 추출 문장). 30문항이라 1문항이 3.3%p다.
- official111은 v6 데이터를 만들 때 오답을 보고 보강한 세트라 v6에 유리하다. haechan34·새 시험 30이 상대적으로 덜 맞춰진 세트다.
- 완전 일치는 되묻기·거절 문구가 정답과 글자까지 같아야 맞는다. 모델 판단을 보려면 구조 일치를 본다.
- 모델 출력은 ws6 `runs/eval_fx56-hyeonkyeong/`(8B), `runs/eval_fx6-4b-hyeonkyeong/`(4B)에 있다.
- 이 점수는 서버(4090, 4비트 NF4)에서 낸 것이다. 앱은 노트북 4060에서 GGUF Q4_K_M으로 돌리므로 앱 테스트에서 다시 확인한다.
