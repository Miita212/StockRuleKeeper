# data_v6 라벨 점검 (haechan, 2026-11-08)

v4 3에폭의 남은 약점 중 "되묻기 사유·대상 하락"과 "넘는(>)을 이상(>=)으로 읽는 부등호 오답"의 원인을 학습 데이터에서 찾았다.
데이터 파일(jsonl)은 커밋하지 않고, `build_v6.py`로 data_v5에서 다시 만든다.

## 1. 되묻기 기준: 공식 평가셋과 학습 데이터의 기준은 대체로 같다
공식 평가셋 되묻기 30건 중 v4 3에폭이 틀린 12건을 학습 데이터의 가장 비슷한 문장과 하나씩 비교했다.

| 틀린 문장 (정답) | 학습 데이터에서 본 것 | 결론 |
|---|---|---|
| 빚 걱정 없는 회사만 (고르기 1·2·3) | 1·2·3 고르기는 "빚 때문에 위험한 회사는 싫어요" 1건뿐, "대출 많은 회사"는 1·2 고르기 6건, 그 밖의 빚 문장은 대부분 지표 하나의 값 묻기 | 넓은 말인데 학습 예시가 적음 → 보강 |
| 잘 버는 회사만 (고르기 5·6·7) | 5·6·7 고르기 예시는 있으나 "벌이·잘 번다" 표현이 적음 | 보강 |
| 규모가 큰 회사 (고르기 14·19) | "덩치/시총 큰 회사"는 값 묻기 14가 42건 | 기준 충돌(규모=시총만이냐 거래대금도냐). 기존 라벨은 건드리지 않고 "규모" 표현 보강 |
| 이익이 늘어나는 회사가 좋아 (고르기 8·9) | "이익이 (계속) 늘어나는 회사"는 값 묻기 9가 37건 | 기준 충돌. 건수가 많아 바꾸지 않음(3번) |
| 주가가 롤러코스터 같은 종목 (고르기 16·18) | "롤러코스터 타는 주식"은 값 묻기 18 | 기준 충돌, 소수라 바꾸지 않음 |
| 저점에서 아직 안 오른 종목 (값 묻기 17) | 저점·바닥에서 회복·반등 문장은 모두 고르기 15·17(data_v4 B4), "저점 대비 오른"은 값 묻기 17 | B4는 되돌리지 않음. "안 오른/덜 오른" 대비 예시 보강 |
| 자산가치 대비 저렴한 회사 (값 묻기 11) | "자산 대비 저평가"는 값 묻기 11이 21건, "저평가된 주식"은 고르기 10·11 | "저렴한" 표현 대비 예시 보강 |
| 최근 주가가 많이 내린 종목 (기간 묻기 15) | "최근 기간에 오른"은 기간 묻기 15, 내린 쪽 예시는 거의 없음 | 내린/떨어진 기간 묻기 예시 보강 |
| 남는 장사하는 회사가 좋아 (값 묻기 7) | 비슷한 문장을 7이 아닌 지표로 답함 | 보강 |
| 가성비 좋은 주식 찾아줘 (고르기 10·11·16) | 모델이 거절함. "찾아줘"로 끝나는 되묻기 예시 부족 | 보강 |
| 배당주 투자하고 싶어요 | 사유·후보 모두 맞고 후보 키 이름만 다름(name/label). 채점은 지표 번호만 봄 | 정상 |

- **B4 재라벨은 되돌리지 않았다.** 되돌리면 같은 시트의 다른 결정(B6, 14행)과 일관성이 깨지고, 오답 원인은 "회복·반등"이 아니라 "아직 안 오른"이라는 다른 표현이다.
- **후보 키 이름이 두 가지다.** 학습 데이터의 고르기 후보는 `name` 345건 · `label` 70건이 섞여 있다. 백엔드 `principle.py`는 둘 다 읽고(`label or name or area`) 채점도 번호만 보므로 동작 문제는 없어 그대로 두었다.
- 사유가 갈린 문장 상당수는 사람마다 갈릴 수 있는 경계 사례다. 라벨을 평가셋에 맞춰 대량으로 바꾸면 점수만 오르고 일반화는 아닐 수 있어서, **건수가 많은 라벨은 바꾸지 않고 틀린 쪽 표현의 대비 예시를 보강하는 쪽**으로 정했다.

## 2. 부등호 라벨: 실제 오류 35행을 바로잡았다
단일 지표 추출 행에서 문장의 '이상/이하/미만/넘는/초과'와 정답 부등호를 비교해 어긋난 행을 직접 읽고 골랐다(제외하는 문장은 남길 범위로 뒤집어 판단). 행별 기록은 `EDIT_LOG_v6.csv`.
- 이상 → `>=` : 시총 5조, 6개월 수익률 20%, 영업이익 1000억 등 12행
- 이하 → `<=` : "시총 1조 이하" 5행 + PER 10배 이하(val) 1행
- 미만 → `<` : PBR 1배, PER 15배, 부채비율 100% 등 7행
- 넘는 → `>` : 영업이익 증가율 10%를 넘는, 매출 성장률 15% 넘는 2행
- 넘는/초과하지 않는을 남길 범위로 → `<=` : 부채비율 100% 2행
- "수익률 0% 이하인 종목은 제외" → 남길 범위 `> 0` : 6행
- 단일 지표 행만 본 것이라 전수는 아니다. "넘는"은 `>` 32 : `>=` 4로 대부분 맞게 붙어 있었다. 그래서 E 그룹의 "넘는→이상" 오답은 라벨 오류보다 **두 지표 이상 문장에서 부등호를 섞어 쓰는 예시 부족**이 원인으로 보여 보강(`gen_aug_v6.py`)으로 다룬다.
- 안 건드린 의심 행: 영업이익 기본값(>0)과 얽힌 "영업이익이 0억원 이상인 회사는 없애고 싶어요", 문장이 깨진 "PBR 0.8배 이하 미만 기업" 등.

## 3. 하지 않은 것
- "이익이 (늘어나는)" 값 묻기 9 37행, "규모/덩치" 값 묻기 14, "롤러코스터" 값 묻기 18의 대량 전환: 평가셋에 맞추는 재라벨이 되므로 보류.
- 학습 데이터 후보 키 통일(name/label).
