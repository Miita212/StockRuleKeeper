## 왜 만들었나 (v3 3에폭 평가에서 틀린 유형)
- **거절 76행 (S5)**: v3는 20개 지표 밖 개념을 지표 이름 없이 풀어 말하면("기관이 많이 사는 종목") 비슷한 지표로 되묻기를 했다. 기존 거절 데이터는 대부분 "ROE 높은 회사"처럼 지표 이름을 직접 말한다. 개념 25개를 넣었다(외국인 지분·순매수, 개인 순매수, 대주주 지분, 내부자 매수, 자사주, 공매도, 신용잔고, 배당성향, 주당배당금, 분기배당, ROE, 매출총이익률, 재고 회전율, 수주잔고, 점유율, 연구개발비, 해외 매출, 업종·테마, 목표주가, 상한가, 이동평균선, ESG, 직원 수, 설립 연도).
- **지표 혼동 157행 (S1 102·S2 55)**: 평가에서 헷갈린 짝(8↔9, 16↔17↔18, 13↔6, 1↔2↔4, 15↔20, 3, 14↔19)을 구분하는 문장을 만들었다. 두 지표 문장 55행은 v3가 하나를 빠뜨리던 유형도 함께 다룬다. 넘는(>)·미만(<)·이상·이하와 "~한 건 빼줘"(남길 범위로 바꿈) 표현을 섞었다.

## 평가 공정성
- 평가셋에서 v3가 틀린 거절 개념(현금 보유액·기관 순매수·배당 성장률·EPS 증가율)과 평가셋의 다른 거절 개념(ROA·ROIC·PEG·MACD·골든크로스)은 **일부러 넣지 않았다**. 현금 계열(PCR 포함)도 뺐다.
- 숫자를 지운 뒤 평가 문장 111개와 문자 2-gram 유사도가 0.75 이상인 문장은 뺐다(1건 빠짐).
- 기존 data_v4 train·val과 같은 문장 0건.

## 검증
- 팀 검증기 V-1(`haechan/data/validate_data.py`, 마스터 byungjun/data, 평가 격리 포함): 233건 전부 통과.
- 정답 JSON은 기존 데이터와 같은 모양(지표 20개 전부, 말한 지표만 source=user, anchors는 번호순, 기간 수익률은 period_months)이다.

## 한계
- 틀(템플릿)로 만든 문장이라 표현이 기존 데이터보다 단조롭다. 문장을 사람이 한 번 읽어 보는 게 좋다.
- 거절 메시지의 대안 지표 두 개는 내가 고른 것이다.

# aug6 (v5 학습용 보강, 2026-11-08)

`gen_aug_v6.py`로 만든다(seed 고정). v4 3에폭의 남은 약점을 겨냥한 247행(train 223 / val 24)이고, `data_v6/build_v6.py`가 data_v5 뒤에 붙인다.

| 종류 | 행 | 내용 |
|---|---|---|
| 부등호·끝말 한 지표 (S1) | 132 | 넘는·초과(>), 안 되는·미만(<), 넘지 않는(<=), 이상·이하. 영업이익·배당수익률·순이익률·PBR·PER·변동성·고점 대비(16) 등. 끝말은 "찾아줘·골라줘·알려줘" 위주 |
| 부등호 두 지표 (S2) | 66 | 위 표현을 섞은 두 지표 문장(예: 영업이익 100억 초과 + 부채비율 150% 이하) |
| 되묻기 (S3) | 49 | 넓은 말은 고르기(빚 부담 1·2·3, 벌이 5·6·7, 규모 14·19, 가성비 10·11·16), 지표 하나로 읽히는 말은 값 묻기(저점 대비 덜 오른 17, 자산 대비 싼 11, 마진 7, 배당 짭짤한 12 등), 기간 없는 오름·내림은 기간 묻기(15). 끝말이 "찾아줘·골라줘"인 것 포함 |

- 공정성: 공식 평가셋과 2-gram 0.75 이상, 시험(`test_haechan`·`test_haechan_v5`)과 0.6 이상인 문장은 뺐다(평가와 비슷 5건 제거). 단 **'가성비' 개념은 공식 평가셋에도 있다**(문장은 다름). 이 부분의 공식 점수 상승은 개념 보강 효과가 섞이므로 `test_haechan_v5`의 "가격 대비 효율" 문장으로 따로 확인한다.
- 값 묻기·기간 묻기 정답은 학습 데이터의 같은 (사유, 지표) 정답을 그대로 가져왔고, 고르기 정답은 기존 형식(`candidates`: id·name)으로 직접 만들었다.
- 검증: 팀 검증기 V-1을 data_v6 전체(5,922행)에 돌려 전부 통과(처음 5건이 배당수익률에 `<`를 써서 걸려 해당 틀을 뺐다).
- 한계: 문장 틀로 만들어 표현이 단조롭다. 시험 v5 31건도 사람이 쓴 문장이라 학습과 표현을 달리했다.
