# D2. 기관별 금융 용어 자료 찾기·이용조건 확인

작성: haechan / 2026-11-04 / 방법: 웹 검색·공공데이터포털 페이지 조회
목적: D1(금융위원회 금융용어사전)과 같은 용어를 다른 기관이 어떻게 설명하는지 대조할 출처를 찾는다.

| 기관 | 자료 | 위치 | 형태 | 이용조건 (확인된 것) |
|---|---|---|---|---|
| 금융위원회 | 금융용어사전 | https://www.data.go.kr/data/15160317/fileData.do | **PDF 파일** (공공데이터포털 파일데이터) | 이용허락범위 **확인 못 함** |
| 한국예탁결제원 | 금융용어조회서비스_GW | https://www.data.go.kr/data/15158905/openapi.do | **API** (XML). 용어를 넣으면 설명 반환, 설명에 HTML 태그 포함 가능(용어 200자, 설명 4,000자까지) | 공공저작물 제2유형: **출처표시, 상업적 이용금지** |

| 한국거래소 | 용어사전 | 이번 검색에서 이용조건 못 찾음 | - | **확인 못 함** |

## 발견한 점
1. **계획표와 다른 점:** 계획표 D1은 금융위원회 용어를 "파일/API"로 적었는데, 검색상 금융위원회 자료는 PDF 파일이고 API로 확인된 것은 **한국예탁결제원** 것입니다. D1 담당(hyeonkyeong)에게 알려야 합니다.
2. **HTML 태그 문제:** 예탁결제원 API는 설명에 HTML 태그가 들어갈 수 있다고 적혀 있어, D1의 "정제" 작업과 맞는 내용입니다.
3. **상업적 이용금지:** 예탁결제원 자료는 상업적 이용이 금지됩니다. 우리 프로젝트가 상업 서비스로 판단되면 학습 데이터로 쓸 수 없습니다. 팀 확인이 필요합니다.
4. 한국은행 700선은 책자 PDF가 있지만, 학습 데이터로 써도 되는지는 확인하지 못했습니다. **정의 대조용(읽고 비교)** 으로만 쓰고, 문장을 복사해서 학습 데이터에 넣지 않는 것이 안전합니다.

## 남은 확인
- 금융위원회·금감원·거래소·한국은행 각 사이트의 저작권 표기(공공누리 유형) 직접 확인
- 대조에 쓸 용어 2개 이상 선정 후 기관별 설명 비교표 작성 (계획표 완료 기준: 같은 용어 2개 기관 설명 비교). 이 표는 지표 마스터(H1)가 확정되면 20개 지표 용어로 채우는 것이 효율적
