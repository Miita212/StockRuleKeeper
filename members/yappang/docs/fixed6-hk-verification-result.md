작성: 2026-11-10, yappang. 대상: `train_model_q4b/fixed6-hk-data-2026-11-09`(hyeonkyeong, fixed5-hk에 표현 기준 G1~G7 반영).
방법: 해시·건수 확인, fixed5-hk와 줄 단위 대조, `data/scripts/check_new_data.py`, 충돌·중복 직접 집계, 보강 47건 전수 읽기, 시험 정답 제안 9건 대조.

## 1. 결론

- 데이터는 건강하다. 해시·건수·형식이 맞고, 같은 문장에 다른 정답이 붙은 경우가 0건이다.
- 지난번 지적(홀드아웃 N019 중복, 일반 문구 88개)은 반영됐다.
- 남은 쟁점은 3개다(3절). 학습을 막을 오류는 없다.
- 시험 정답 수정 제안 9건은 기준에 맞아 적용했고, 같은 기준인데 빠진 T194를 더해 **10건**을 `test_set.jsonl`에 반영했다(4절).

## 3. 남은 쟁점

| # | 내용 | 심각도 |
|---|---|---|
| 1 | 학습 "돈 되는 장사 하는 회사가 좋아요"(모호[5,7], 8줄 같은 계열) ↔ 시험 T028 "남는 장사하는 회사가 좋아"(매출순이익률 값 되묻기 7). 유사도 0.83, 정답은 다르다. 모델이 "장사"를 [5,7]로 배우면 T028이 틀릴 수 있다 | 중 (누수는 아님, 정답 충돌) |
| 2 | "싸다" 후보가 아직 2종: [10,11] 119건, [10,11,16] 19건("할인 중인 종목" 등). G4는 가성비만 바꿨고 "할인 중"은 그대로다 | 낮음: 팀이 "할인"을 16으로 볼지 정해야 함 |
| 3 | 학습 "주식이 급락하면 피하고 싶은 마음이 있어"가 변동성(18) 값 되묻기로 남아 G2(급락 → 모호[15,16])와 어긋난다 | 낮음 (1줄) |

참고: 홀드아웃 30문항 중 14문항은 학습 문장과 유사도 0.65 이상이다(주로 숫자가 든 추출 문장). hk가 밝힌 대로 "처음 보는 문장" 점수로 읽지 않는다.

## 4. 시험 정답 수정 (적용함)

`test_set.jsonl` 정답 10건 수정. 수정 전 `data/backup/2026-11-10/test_set_before_g1g7.jsonl`, 코드 `data/scripts/apply_test_fixes_20261110.py`. 후보 키(label/name)는 문항 원래 형식을 유지했다.

| id | 문장 | 전 | 후 |
|---|---|---|---|
| T031 H5a-031 | 잘 버는 회사만 볼래요 | 모호[5,6,7] | 모호[5,7] |
| T228 HT7-028 | 돈 잘 버는 회사만 보여줘 | 모호[5,6,7] | 모호[5,7] |
| T064 H5b-028 | 가성비 좋은 주식 찾아줘 | 모호[10,11,16] | 모호[10,11] |
| T229 HT7-029 | 가격 매력 있는 종목 골라줘 | 모호[10,11,16] | 모호[10,11] |
| T194 HT5-025 | 가격 대비 효율 좋은 종목 알려줘 | 모호[10,11,16] | 모호[10,11] (제안에 없던 추가) |
| T065 H5b-029 | 이익이 늘어나는 회사가 좋아 | 모호[8,9] | 영업이익 증가율(9) 값 되묻기 |
| T106 H5c-034 | 주가가 롤러코스터 같은 종목 | 모호[16,18] | 변동성(18) 값 되묻기 |
| T107 H5c-035 | 규모가 큰 회사 | 모호[14,19] | 시가총액(14) 값 되묻기 |
| T193 HT5-024 | 크기가 큰 상장사만 보여줘 | 모호[14,19] | 시가총액(14) 값 되묻기 |
| T197 HT5-028 | 최근 주가가 푹 꺼진 종목 | 기간 되묻기[15] | 모호[15,16] |

- 근거: hk의 G1~G7 기준(말뜻이 지표 하나면 값 되묻기, 두 가지로 읽히면 모호). T194는 G4가 "가격 대비"를 포함하고 학습 "가격 대비 괜찮은 회사"가 [10,11]이라서 같이 고쳤다.
- 이 10문항은 학습 쪽 기준에 시험을 맞춘 것이라 점수가 오르기 쉽다. **이 날 이전 점수와 직접 비교하지 않는다.** 새 기준 점수가 필요하면 10문항을 따로 떼어 낸다.
- v4 기존 출력을 새 정답으로 다시 채점: 완전 일치 155/234(66.2%)로 같고, 구조(유형·지표 id) 일치는 207 → 209. 문항별로는 6건이 새 정답과 맞게 되고 4건이 어긋난다.
- 출렁·요동: 시험에 따로 모호[16,18] 정답인 문항은 없다(롤러코스터 1건뿐).
- holdout 30(N001~N030)은 `test_set.jsonl`에 넣지 않았다. 시험 파일을 하나로 두기로 한 결정과 문항 수 변경은 사용자 확인 후 진행.
