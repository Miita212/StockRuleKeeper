## 3. 잘 된 점

- 필드 정확도 95.3%로 목표(90%)를 넘었다. v1 63.7% → v2 78.8% → v3 90.0%에서 계속 올랐다.
- JSON 유효율 100%.
- 공식 111문항 완전 일치율이 v3 대비 +9.9%p(65.8% → 75.7%). 목표 70%를 넘었다.
- 단일 지표, 복수, 오타·구어, 별칭 변환은 대부분 맞는다.
- 데이터 정리(부등호·조사 수정, 약한 유형 보강, v6 반영)가 효과를 낸 것으로 보인다(해석).

## 4. 문제점 (현상 → 원인)

| # | 현상 | 원인 |
|---|---|---|
| 1 | **지표 모호 되묻기 2/9** | (a) 모호를 값 되묻기로 단정: "이익이 늘어나는 회사", "배당주 투자하고 싶어요" (b) 모호를 거절로 답함: "빚 걱정 없는 회사만" (c) 되묻기는 맞는데 문구·후보 불일치: "튼튼한 회사" → "안전하다고…". 학습에 "성장"(8·9) 124건, "배당"(12·13) 52건이 이미 있어 양보다 표현 일반화·경계 학습이 부족한 것으로 보임(해석, 검증 전) |
| 2 | 값 되묻기 14/18 (목표 17) | 지표 모호와 값 되묻기 경계가 섞임. 모호 비중이 큰 데이터의 부작용 가능성(v3부터의 가설, 미검증) |
| 3 | 20개 밖 개념 거절 오류 4건 | "현금 보유"는 모호 되묻기로, "배당 성장률"은 배당수익률 값 되묻기로, "MACD 골든크로스"는 이동평균선 거절로 답함. 학습의 거절은 "MACD 높은 회사" 같은 한정된 표현이라 변형 표현에 약함. "PER나 PBR로" 한 건은 문구 차이 |
| 4 | 새 문장 일반화 약함 (haechan34 35.3%) | 학습에 없는 표현에 약함. 8B는 같은 세트에서 더 높음(v5·v7 기준, 아래 6절) |
| 5 | 문구만 다른 오답이 완전 일치율을 낮춤 | 모호 되묻기 메시지·후보 집합이 데이터 안에서 통일돼 있지 않음. 일반 문구("어떤 기준으로 볼까요?")가 89건 섞여 있음 |
| 6 | 정답 측 문구 오류 (해결됨) | 공식 111문항 거절 정답 8건의 조사 오류. 학습 데이터의 거절 문구는 오류 0건(317건 확인) |

## 5. 개선사항

세부 초안은 `docs/fixed5-draft.md`. 요약:

| 구분 | 내용 | 규모 | 학습 필요 |
|---|---|---|---|
| 데이터 A | 주제어별 대조쌍(모호 문장 + 지표 하나로 정해지는 문장) | 약 120쌍(240건) | 예 |
| 데이터 B | 20개 안 지표 이름이 겹치는 모호 문장을 되묻기로 답하는 예시 | 약 40건 | 예 |
| 데이터 C | 20개 밖 개념 표현 변형(현금 보유, 배당 성장률, MACD 골든크로스 등)과 20개 안 지표와의 대조쌍 | 약 100건 | 예 |
| 데이터 D | 모호 메시지(사용자 말 인용)와 주제어별 후보 집합(오름차순) 통일 | 기존 100~200건 수정 | 예 |
| 채점 | 구조 일치 지표(되묻기 이유 + 후보 id 집합, 거절 여부) 추가, 문구 차이와 모델 오류 분리 | - | 아니오 |
| 비교 | 8B와 같은 `test_set.jsonl`·채점기로 비교 요청 | - | 아니오 |

판단 기준(초안): 사용자 말이 가리키는 20개 중 지표가 둘 이상이고 지목하지 않았으면 모호, 하나면 값 되묻기, 값까지 있으면 변환. 확정 전 확인 사항은 "싸다" 후보 통일(10·11·16 vs 10·11), "매출이익률"(5·6·7)·"주요 활동 수익성"(5·7·8·9) 후보 점검이다.

목표(v5): 값 되묻기 17/18 이상, 지표 모호 5/9 이상, 필드 정확도 90% 이상 유지, 공식 111 완전 일치 80% 이상, haechan 세트 개선 확인.

## 6. 아직 확인하지 않은 것

- v4 학습의 에폭 수, 손실값, 체크포인트 선택(로그 없음)
- 공식 111문항만 따로 낸 필드 정확도·은어 변환율
- 8B(v5·v7)와의 같은 세트 비교 — haechan의 이전 비교는 Q4B v1 기준이었고 v3·v4는 들어 있지 않음
- 어댑터 병합, GGUF Q8_0 변환, Ollama 등록 후 품질과 백엔드 실제 연동
- 위 4절 원인 중 해석으로 표시한 것(모호 비중 부작용, 표현 일반화 부족)의 검증

## 7. 결론

필드 정확도 95.3%, 공식 111 완전 일치율 75.7~79.3%로 v3보다 분명히 좋아졌고 시연용 4B로 쓸 수준에는 도달했다. 지표 모호 되묻기(2/9)와 새 문장 일반화(haechan34 35.3%)가 남은 약점이다. 거절 0/8은 정답 문구 오류가 대부분이어서 4/8로 올랐지만, 20개 밖 개념의 표현 변형에는 여전히 약하다. 다음 단계는 fixed-5(위 5절)와 구조 일치 지표, 8B와의 같은 세트 비교다.
