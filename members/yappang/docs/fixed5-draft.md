# fixed-5 수정 초안 (확인용)

작성: 2026-11-09, yappang. 근거: v4 평가(234문항) 오답, `train_fixed4.jsonl` 집계.
**이 문서는 초안이다. 아래 3절의 기준·후보 집합을 확인받은 뒤에 데이터를 만든다.** 학습은 시작하지 않는다.

## 1. 현상 → 원인 → 대책

| 구분 | 현상(v4) | 원인(해석 포함) | 대책 |
|---|---|---|---|
| A | 지표 모호를 값 되묻기로 단정 ("이익이 늘어나는 회사", "배당주 투자하고 싶어요") | 학습에는 "성장"(8·9) 124건, "배당"(12·13) 52건이 이미 있는데 표현이 바뀌면 지표 하나로 단정. 표현 일반화 부족 | 같은 주제어를 모호/단일/값 되묻기로 가르는 대조쌍 추가 |
| B | 모호를 거절로 답함 ("빚 걱정 없는 회사만" → 부채비율 거절) | 20개 안 지표 이름과 비슷한 말을 20개 밖으로 오판 | 20개 안 이름이 겹치는 모호 문장을 되묻기로 답하는 예시 추가 |
| C | 20개 밖 개념을 다른 유형으로 답함 ("현금 많이 쌓아둔", "배당 성장률", "MACD 골든크로스") | 학습의 거절은 "MACD 높은", "잉여현금흐름 좋은" 등 한정된 표현. 변형 표현에 약함 | 20개 밖 개념별 표현 변형과 20개 안 지표와의 대조쌍 추가 |
| D | 모호 메시지·후보가 정답과 다름 ("튼튼한" → "안전하다고…") | 같은 주제어가 다른 후보 집합·문구로 섞여 있음. 일반 문구("어떤 기준으로 볼까요?")가 89건 | 주제어별 후보 집합과 메시지 규칙 통일 |

정정: 학습 데이터 거절 문구의 조사 오류는 **0건**이다(20개 밖 거절 317건 모두 "로 볼 수 있어요"). 조사 교정은 시험 정답에만 필요했고 이미 끝났다.

## 2. fixed-4 현황 (측정값)

- 지표 모호 되묻기 1,237건(마지막 응답 기준), 후보 집합 29종. 후보 수 2개 715 / 3개 485 / 4개 113 (집계 시점의 1,313은 다른 기준).
- 일반 문구 메시지 89건, 주제어 인용 문구 1,148건.

## 3. 확인받을 초안

### 3.1 "모호" 판단 기준 (한 줄)
> 사용자 말이 가리키는 20개 중 지표가 **둘 이상**이고, 사용자가 그중 하나를 **지목하지 않았으면** 모호(AMBIGUOUS_INDICATOR). 지표가 **하나**로 정해지고 값이 없으면 값 되묻기(VALUE_MISSING), 값까지 있으면 변환.

판단표:

| 사용자 말 | 가리키는 지표 | 유형 |
|---|---|---|
| "배당주 투자하고 싶어요" | 12·13 (수익률/연속) | 모호 |
| "배당을 1년에 몇 %나 주는지 봐요" | 12 | 값 되묻기 |
| "배당수익률 3% 이상" | 12 | 변환 |
| "이익이 늘어나는 회사" | 8·9 | 모호 |
| "본업 이익이 느는 속도" | 9 | 값 되묻기 |

### 3.3 메시지 규칙 (제안)
- 첫 구절은 **사용자가 쓴 말의 핵심어를 그대로 인용**한다. 예: "튼튼한 회사" → "튼튼하다고 볼 수 있는 기준이 여러 가지예요. 어떤 걸로 볼까요?"
- 핵심어가 없으면 일반 문구("어떤 기준으로 볼까요? 아래에서 골라 주세요.")를 쓴다. 일반 문구는 지금 89건이라 늘리지 않는다.
- 후보 id는 **오름차순**으로 나열하고, 같은 주제어는 항상 같은 집합을 쓴다.

## 4. 추가할 데이터 규모 (시작안)

| 항목 | 규모 | 내용 |
|---|---|---|
| A. 대조쌍 | 약 120쌍(240건) | 주제어 12종(배당·이익/성장·빚/이자·안전·싸다·거래·규모 등) × 약 10쌍. 쌍 하나 = 모호 문장 + 지표 하나로 정해지는 문장 |
| B. 거절 오판 방지 | 약 40건 | 20개 안 지표 이름·별칭이 들어간 모호 문장 → 되묻기 |
| C. 20개 밖 변형 | 약 100건 | 현금 보유·배당 성장률·MACD(골든크로스 등)·PEG·ROE류 등 개념당 3~5 표현 + 20개 안 지표와의 대조쌍 |
| D. 통일 | 기존 약 100~200건 수정 | 3.2·3.3에 맞춰 메시지·후보 정리 |

합계 신규 약 380건, 수정 100~200건. 시험 234문항과 동일 문장 0건 검사를 유지한다. 신규는 템플릿+어휘 조합으로 직접 생성하고, 수작업 검수 샘플을 사용자가 본다.
