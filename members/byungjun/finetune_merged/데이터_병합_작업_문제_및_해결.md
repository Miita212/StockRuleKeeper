# 데이터 merge 작업 정리 (발표 자료용)

> 작성: byungjun / 2026-11-05

## 1. 목표
- Qwen3-8B를 4090에서 QLoRA로 학습할 데이터를 준비한다. 학습 데이터가 팀원 폴더(`members/*/data`)에 흩어져 있어 하나로 합쳤다.
- 조건: 팀원 원본은 수정·삭제하지 않고, 결과는 byungjun 폴더에 저장한다.

## 2. 과정

| 단계 | 한 일 | 결과 |
|---|---|---|
| ① 전수 조사 | 각 폴더의 `data` 파일 약 60개를 확인하고 형식·용도를 구분 | 학습 후보 6개, 평가용 3개, 구버전 2개, 생성용 프롬프트 2개 등으로 분류 |
| ② 형식 확인 | 후보가 모두 `messages`(system/user/assistant) 형식인지, 인코딩·중복 확인 | UTF-8, 깨진 글자 0, 건 전체 중복 0 |
| ③ 사전 검증 | haechan의 V-1 검증기(`validate_data.py`)로 원본 전체 검증 | 2,207건 모두 통과 |
| ④ 병합 | `merge_train_data.py`로 합치고 종류별 약 5%를 검증용으로 분리 | 시드 42 고정(재현 가능) |
| ⑤ 검증·정리 | 결과를 다시 검증하고 README 작성, push | 학습 2,090건 / 검증 111건 |

**합친 데이터 (6개 파일, 2,207건)**

| type | 내용 | 원본 | 건수 |
|---|---|---|---|
| SEED | 시드 | haechan `seed_*.jsonl` | 207 |
| S3 | 되묻기(다중 턴) | hyeonkyeong `gen_s3.jsonl` | 364 |
| S4 | 기존 규칙 수정 | hyeonkyeong `gen_s4_s5.jsonl` | 700 |
| S5 | 거절 | hyeonkyeong `gen_s4_s5.jsonl` | 306 |

**합치지 않은 것**
- `eval_*.jsonl`: 평가용이라 학습에 넣지 않음
- `dev_set.jsonl`, `pilot_labels.jsonl`: 11/04 회의 전 Qwen2.5 기준 구버전
- `prompts_s1/s2.jsonl`: 데이터를 만들 때 쓰는 프롬프트
- S1·S2 학습 데이터(`gen_s1_s2.jsonl`): 아직 생성되지 않음. 사용자 확인으로 지금은 없어도 되는 것으로 정함

## 3. 발견한 문제와 해결

| # | 문제 | 원인 | 해결 |
|---|---|---|---|
| 1 | **평가 세트가 학습에 섞임**: S3 6건의 첫 질문과 답이 평가 H5b-024("배당 많이 주는 회사"), H5b-026("매출이 쑥쑥 크는 회사")와 같음 | 생성 과정에서 평가 문장이 학습 쪽에도 만들어진 것으로 보임 | 병합 스크립트가 평가와 같은 첫 질문을 자동 제외(6건). 원본은 그대로 두고 hyeonkyeong에게 알릴 사항으로 기록 |
| 2 | **검증 데이터가 학습 데이터와 겹침**: S7 val 10건의 입력이 모두 train에도 있었음 | 검증용을 건 단위로 무작위로 뗐기 때문. 원본 S7에 같은 입력이 3번씩 나오는 그룹 60개가 있어 더 심했음 | 같은 첫 질문은 한쪽에만 들어가도록 입력 단위로 분할. 종류가 달라도 같은 질문이면 묶음(SEED와 S3 1건 추가 발견). 최종 겹침 0 |
| 3 | 검증기가 병합본을 단독으로 통과시키지 못함 | `train.jsonl`에는 `locked` 정보가 없어 V5 실패 | 메타 파일을 다시 붙여 검증(2,201건 실패 0). README에 방법 기록 |

- 문제 2는 팀원의 Claude가 병합본을 읽고 먼저 지적했고, 이후 데이터로 확인해 수정했다. 처음 README에 "검증 이상 없음"이라고만 적었는데 입력 기준 겹침은 확인하지 않은 상태였다.

## 4. 남은 사항 (발표에서 한계로 언급)
- **S7 중복**: 원본 S7에 같은 입력 60그룹(각 3번, 답변만 다름, 초과분 120건)이 있다. 말투 변형으로 보고 유지했지만 학습량이 부풀려 보이는 효과가 있다. 정리 여부는 결정 대기.
- **S6 템플릿 의존**: 답변 문구가 같은 건이 285건(템플릿 생성).
- **S1·S2 부재**: 값 없는 문장의 되묻기, 복수 지표 JSON 같은 핵심 유형이 아직 병합본에 없다.
- **학습 설정 미정**: S3가 다중 턴이라 마지막 답변에만 loss를 줄지 정해야 한다. 시스템 문구도 팀 합의 전 임시다.
- **환경**: 노트북 RTX 4060(8GB)에서는 8B QLoRA가 빠듯해 4090에서 학습한다.

## 5. 발표 핵심 메시지
1. 팀원 4명이 따로 만든 데이터를 원본을 건드리지 않고 하나의 학습 세트로 합쳤다 (2,207건 → 학습 2,090 + 검증 111).
2. 병합 중 평가 누출 6건과 train/val 겹침을 발견해 고쳤고, 겹침 0을 확인했다.
3. 재현할 수 있게 스크립트(시드 고정)와 README를 남겼고, 검증기 통과를 확인했다.
