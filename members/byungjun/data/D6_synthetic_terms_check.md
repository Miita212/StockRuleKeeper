# 합성 데이터 생성 서비스 약관 확인 (D6)

> 작성: byungjun / 2026-11-04 / 상태: **1차 조사 (웹 검색 요약 기준, 약관 원문 재확인 필요)**
> 질문: 외부 LLM으로 학습 데이터를 만들고 그 데이터로 Qwen3-8B를 파인튜닝해도 되는가?
> **결론: 조건부 — 기본은 로컬 모델로 생성하고, 외부 LLM은 원문 확인과 팀 합의 뒤에만 쓴다.**

## 결정 (제안)
1. **생성 방법: 로컬 모델 우선.** 말투·오타 변형(S1)처럼 문장을 불리는 작업은 파인튜닝 전 Qwen3-8B 등 로컬 오픈 모델로 생성한다.
2. 외부 LLM(Claude 등)은 **학습 데이터 생성에 쓰지 않는다.** 필요하면 소량의 **품질 비교·검수 용도**로만 쓰고, 그 출력은 학습 데이터에 넣지 않는다.
3. 외부 LLM으로 학습 데이터를 만들어야 하는 사정이 생기면, 그 시점의 약관 원문을 다시 읽고 팀이 합의한 뒤 진행한다.
4. 이번에 `members/byungjun/data/`에 만든 합성 파일(`S-4_gen_s6_s7.jsonl`)은 **외부 LLM 없이 템플릿 스크립트로 생성**했다. 약관 이슈가 없다.
