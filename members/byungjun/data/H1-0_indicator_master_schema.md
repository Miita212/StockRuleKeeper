## 1장. 양식 (지표 1개 = 1행)

마스터 파일(`H1-a_indicator_master_1-7.json`, `H1-b_indicator_master_8-13.json`, `H1-c_indicator_master_14-20.json`)은 아래 필드를 가진 객체의 배열이다.

| 필드 | 필수 | 형식 | 설명 | 예 (부채비율) |
| --- | --- | --- | --- | --- |
| `id` | O | 정수 1~20 | 지표 번호. 모델은 **항상 id만 출력**하고 이름은 코드가 붙인다 | `1` |
| `name` | O | 문자열 | 정식 이름 (핵심지표20개.xlsx의 "지표") | `"부채비율"` |
| `ui_name` | O | 문자열 | 화면에 보이는 이름. 화면마다 다르면 가장 많이 쓰는 것 하나 | `"부채비율"` |
| `abbr` | O | 문자열 | 약어·짧은 이름 | `"부채"` |
| `area` | O | 문자열 | 영역 7종 중 하나: 재무 건전성 / 수익성 / 성장성 / 가치 / 배당 / 규모 / 주가·거래 | `"재무 건전성"` |
| `operator` | O | `<=` `>=` `<` `>` | **기본 방향**. 2장 규칙 1 참고 | `"<="` |
| `allowed_operators` | O | 배열 | 사용자가 반대로 말해도 허용되는 부등호 (보통 `[operator]` 하나) | `["<="]` |
| `unit` | O | `%` `배` `년` `억원` | 값의 단위. 2장 규칙 3 참고 | `"%"` |
| `default` | O | 숫자 | 사용자가 값을 말하지 않았을 때 쓰는 기본 기준값 | `100` |
| `min` / `max` | O | 숫자 | 허용 범위. 검증 V3가 이 범위 밖 값을 버린다 | `0` / `1000` |
| `step_stricter` | O | 문자열 | "더 엄격하게" 요청 시 움직이는 규칙 | `"기준값의 20% 낮춤"` |
| `definition` | O | 문자열 | 쉬운 정의 + 좋은 방향 한 문장 | `"부채총계 ÷ 자본총계 × 100 (낮을수록 빚 부담이 적음)"` |
| `source` | O | 문자열 배열 | 정의의 **출처** (기관명+문서명 또는 URL). 최소 1개 | `["금융위원회 금융용어사전"]` |
| `data_source` | O | 문자열 | 데이터를 어디서 얻는지 (직접/계산 + KIS 필드) | `"직접: 종목별 안정성비율 lblt_rate"` |
| `alias` | 선택 | 문자열 배열 | 화면마다 다른 이름·약어 (E21) | `["부채 비율"]` |
| `note` | 선택 | 문자열 | 팀 확인이 필요한 부분. `[추론]`, `[임의값]` 표시 | `"default 100은 Figma 샘플 값 [임의값]"` |

## 2장. 규칙

### 규칙 1. 부등호는 4종만 쓰고, 지표마다 "기본 방향"을 고정한다
- `operator`는 `<=` `>=` `<` `>` 중 하나. 사용자 말의 이하·이상·미만·초과를 그대로 대응시킨다.
- 기본 방향은 "좋은 쪽"으로 고정한다. 예: 부채비율은 낮을수록 좋으니 `<=`, 배당수익률은 `>=`. 방향이 반대로 적히면 큰 오류라서 검증 V4가 막는다.
- 사용자가 반대 방향을 말할 수 있는 지표(시가총액 상한, 기간 수익률 하락 종목 등)는 `allowed_operators`에 반대 부등호도 적는다. 허용되지 않은 부등호가 나오면 검증에서 버린다.
- 기간 수익률(15)처럼 방향이 사용자 의도에 따라 갈리는 지표는 `operator`를 `>=`로 두고 `allowed_operators`에 `<=`도 넣는다. 기간(개월)은 마스터가 아니라 조건 값의 별도 필드로 다룬다 `[팀 확인]`.

### 규칙 2. '이내'는 "변화폭이 한도 이하"이며, 저장할 때는 부등호로 바꾼다 `[추론 — 팀 확인 필요]`
- 화면 문구 '이내'는 마스터에 `within` 같은 새 operator를 만들지 않고, **수치 방향에 맞는 부등호로 환산해 저장**한다.
- 52주 고점 대비 `-20% 이내` → 고점보다 20%를 넘게 떨어지지 않음 → `>= -20`
- 52주 저점 대비 `50% 이내` → 저점에서 50%를 넘게 오르지 않음 → `<= 50`
- 근거: 판정서 예시(실제 -8.1% → 충족, 저점 대비 +38% vs '50% 이내' → 충족). 지표 16·17은 부호와 방향이 다르니 `definition`에 부호 예시를 꼭 적는다.
- '이내'라는 표현은 `alias`에 남겨 동의어·진단 문제(E20)에서 쓴다.

### 규칙 3. 단위는 4종, 값은 숫자만 저장한다
| unit | 쓰는 곳 | 저장 규칙 |
| --- | --- | --- |
| `%` | 비율·수익률·변동성 | 50% → `50` (0.5 아님) |
| `배` | PER, PBR, EBITDA/금융비용, 거래량 증가 배율 | 10배 → `10` |
| `년` | 연속 영업흑자·연속 배당 연수 | 3년 → `3` |
| `억원` | 영업이익, 시가총액, 평균 거래대금 | 1조원 → `10000`, 5천억 → `5000` |
- 사용자가 '조', '천억'으로 말해도 마스터·학습 데이터의 정답은 **억원 숫자**로 통일한다. 변환 예시(1조원=10000)를 학습 데이터에 포함한다.
- 변환 때 값이 바뀌지 않게, `definition`에 단위를 한 번 더 적는다.

### 규칙 4. `default`는 근거를 적거나 `[임의값]`이라고 표시한다
- Figma 샘플 값(부채비율 100, PER 10 등)은 임의로 채운 값이다. 근거가 없으면 `note`에 `[임의값]`으로 표시하고, **'업종 평균 ○○' 같은 사실 수치는 `source`가 있을 때만** 쓴다(검증 V10: 마스터에 없는 값은 버림).
- `default`는 `min`~`max` 안에 있어야 한다.
- `step_stricter`는 "기준값의 몇 % 이동" 또는 "몇 단위 이동"처럼 **계산 가능한 문장**으로 쓴다(수정 요청 E13의 100 → 80이 이 규칙에서 나온다).

### 규칙 5. 출처와 완료 점검
- 모든 행에 `source`를 최소 1개 적는다(기관명+문서명 또는 URL). 금융위 용어사전은 D1 결과를 참고한다.
- 3명이 채운 뒤 **다른 1명이 검수**한다(H1-a~c 완료 기준).
- 점검: ① 필수 필드 모두 있음(V1) ② id 1~20(V2) ③ `default`가 `min`~`max` 안(V3) ④ `operator`·`unit`이 아래 고정표와 같음(V4) ⑤ `source` 1개 이상.

### 규칙 6. 이름이 달라도 id는 하나
- 같은 지표가 화면마다 다른 이름으로 나오면(예: 배당수익률 / 12개월 배당수익률, 매출 성장률 / 매출액 증가율) `alias`에 모은다. 모델은 `id`만 출력한다(E21).
- 20개 밖의 지표(ROE, 유동비율, RSI 등)는 마스터에 넣지 않는다. 사용자가 요구하면 거절 데이터(S5)로 처리한다.
