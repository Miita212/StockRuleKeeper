# 되묻기 정책 (H3-0)

> 작성: byungjun / 2026-11-04 / 상태: **제안 (팀원 3명 확인 전)**
> 용도: AI(말 번역기)가 언제 되묻고, 선택지를 어떤 기준으로 만드는지 정한다. 되묻기 선택지(H3-a/b/c), 되묻기 대화 생성(S-2), 시드(H4)가 이 정책을 따른다.
> 기준 화면: Figma 흐름도 "기준이 분명한가요?" → 분명하면 화면 02 원칙 세팅, 아니면 화면 02-1 되묻기.

## 1. 한 줄 원칙
**지표는 정해졌는데 기준값이 없으면 되묻는다. 말이 어느 지표인지 갈리면 지표부터 되묻는다. 그 외에는 되묻지 않고 확정한다.**

## 2. 되묻는 경우 / 되묻지 않는 경우

| 번호 | 상황 | 예 | 처리 |
| --- | --- | --- | --- |
| T1 | 지표는 하나로 정해졌는데 **기준값이 없음** | "빚 많은 회사는 피하고 싶어" → 부채비율, 값 없음 (E05) | **되묻기**: 기준값 선택지 3개 (엄격/보통/느슨) |
| T2 | 한 말이 **여러 지표로 갈림** | "안전한 회사가 좋아요" (E07), "싼 주식" → PER·PBR | **되묻기**: 후보 지표 2~4개를 고르게 한 뒤 T1로 진행 (5개 이상이면 4번 아래 2단계 되묻기) |
| T3 | **기간·방향**이 빠짐 (기간 수익률 등) | "요즘 많이 오른 종목" | **되묻기**: 기간(1/3/6/12개월) 선택지 → 이어서 T1 |
| T4 | 값과 지표가 모두 분명함 | "PER 10 이하" , "적자 기업은 빼고 싶어요"(영업이익 > 0, E08) | **되묻지 않고 확정** |
| T5 | 20개 밖 지표 | "ROE 15% 이상만 보여줘" (E09) | 되묻지 않고 **거절** 안내 + 비슷한 지표 안내 |
| T6 | 투자와 무관 / 종목 추천 요청 | "삼성전자 지금 사도 돼?" (E15) | 되묻지 않고 **거절** (H6 말투 가이드) |

- 값이 분명한 표현("흑자", "적자 제외", "1조 이상")은 기준값이 들어 있으므로 T4로 보고 되묻지 않는다.
- 사용자가 선택지 버튼 대신 **직접 값을 말해도** 같은 결과로 확정한다 ("직접 말해도 돼요", E12).

## 3. 선택지 만드는 기준

1. **항상 3개**: 엄격 / 보통 / 느슨 순서. 값은 `H3-a/b/c_clarify_options_*.json`의 지표별 값을 쓴다.
2. 보통 값은 마스터의 `default`와 **같게** 맞춘다(검증 V10: 마스터와 다른 값은 버림). **예외: 지표 4(자본잠식률), 5(영업이익)**. 이 둘은 `default`가 0이라 이미 범위의 끝값(4는 가장 엄격, 5는 가장 느슨)이라서 엄격/보통/느슨 3개를 만들 수 없다. 이 두 지표는 `default`를 그대로 두고(0 = 잠식 없음, 영업이익 > 0 = 적자 제외, 예시 E03·E08), 선택지의 보통 값만 따로 쓴다(4번 10%, 5번 100억원).
   - 구분 방법: 되묻기 **선택지**에는 `clarify_options_*.json`의 값을, 말하지 않은 지표를 **기본값으로 채울 때**는 마스터 `default`를 쓴다.
   - 예외 여부는 `clarify_options_*.json`의 `normal_equals_default` 필드로 확인한다(false이면 예외).
3. 엄격과 느슨은 보통에서 한 단계씩 벗어난 값이다. 방향은 마스터의 `operator`를 따른다(부채비율은 낮출수록 엄격, 배당수익률은 높일수록 엄격).
4. 각 선택지에 **근거 문장 1개**를 붙인다. 근거는 산식 해석 또는 "임의 예시"로 쓰고, **출처 없는 통계 수치('업종 평균 ○○%')는 쓰지 않는다**.
5. 라벨은 화면 02-1 버튼 문구 형식: `"{값 조건}로 엄격하게 할래요"` / `"…로 보통으로 할래요"` / `"…로 느슨하게 할래요"`.

## 4. 되묻기 메시지 형식 (E05 기준)

```json
{
  "needs_clarification": true,
  "reason": "VALUE_MISSING",
  "indicator_id": 1,
  "message": "빚이 많다는 건 보통 부채비율이 높다는 뜻이에요. 어느 정도까지 괜찮을까요?",
  "options": [
    {"level": "엄격", "label": "50% 이하로 엄격하게 할래요", "value": 50},
    {"level": "보통", "label": "100% 이하로 보통으로 할래요", "value": 100},
    {"level": "느슨", "label": "200% 이하로 느슨하게 할래요", "value": 200}
  ]
}
```
- `reason`: `VALUE_MISSING`(T1) / `AMBIGUOUS_INDICATOR`(T2) / `PERIOD_MISSING`(T3).
- T2는 `options` 대신 `candidates`(지표 id 배열과 한 줄 설명)를 준다. 후보는 **최대 4개**다.
- 메시지 말투는 해요체. 질문은 **한 번에 하나**만 한다.
- **T1의 `message`는 지표별 문구를 쓴다.** 문구는 `clarify_options_*.json`의 `clarify_message` 필드에 지표마다 들어 있다(예: 부채비율 → "빚이 많다는 건 보통 부채비율이 높다는 뜻이에요. 어느 정도까지 괜찮을까요?"). 공통 문구는 `clarify_message`가 없을 때만 임시로 쓴다.

### 후보가 5개 이상일 때 (2단계 되묻기)
후보 지표가 5개 이상이면 버리지 말고 두 단계로 나눠 묻는다.
1. **1단계 (영역 고르기)**: `reason: "AMBIGUOUS_INDICATOR"`, `stage: "AREA"`, `candidates`에 후보가 속한 **영역**(재무 건전성, 수익성, 성장성, 가치, 배당, 규모, 주가·거래) 최대 4개를 준다.
2. **2단계 (지표 고르기)**: 고른 영역 안의 후보 지표(2~4개)를 `stage: "INDICATOR"`로 준다. 한 영역 안의 후보가 5개 이상이면 마스터 순서로 앞 4개만 보여 준다.
3. 지표가 정해지면 T1(기준값 되묻기)로 이어진다.
- 후보가 영역 하나에만 있으면 1단계를 건너뛰고 바로 2단계로 간다.
- 학습 데이터(S3)에서도 후보 5개 이상 표현은 이 2단계 대화로 만들고, 한 번에 5개 이상을 보여 주는 샘플은 만들지 않는다.

## 5. 되묻기 횟수 제한
- 한 조건에 대한 되묻기는 **최대 2번**. 2번 물어도 정하지 못하면 보통(`default`)으로 확정하고 "기본값으로 잡았어요, 나중에 바꿀 수 있어요"라고 안내한다 `[제안]`.
- 확정한 조건은 다시 묻지 않는다.

## 6. 포괄 표현 → 지표 묶음 (T2 후보 규칙, 제안)

| 사용자 말 | 후보 지표(id) | 비고 |
| --- | --- | --- |
| 안전한 / 튼튼한 | 부채비율(1), 차입금의존도(2), 자본잠식률(4), 60일 변동성(18) | 어떤 걸 쓸지 고르게 함 (E07) |
| 싼 / 저평가 | PER(10), PBR(11), 52주 고점 대비(16) | 비싸다 ↔ 싸다 |
| 빚 많은 | 부채비율(1), 차입금의존도(2), EBITDA/금융비용(3) | 겹침 표시 (E04) |
| 잘 버는 / 알짜 | 영업이익(5), 매출순이익률(7), 연속 영업흑자 연수(6) | |
| 큰 회사 | 시가총액(14), 20일 평균 거래대금(19) | |
| 출렁이는 | 60일 변동성(18), 52주 고점 대비(16) | |
| 배당 | 12개월 배당수익률(12), 연속 배당 연수(13) | 둘 다 말했으면 되묻지 않음 (E06) |

묶음은 **팀이 확정하기 전까지 되묻기로 처리**한다(용어위험 2번). 확정되면 이 표를 고친다.

## 7. 팀 확인이 필요한 항목
1. 되묻기 최대 횟수 2번과 이후 기본값 확정 (2단계 되묻기의 영역 단계는 횟수에 넣지 않는다 `[제안]`)
2. 포괄 표현 묶음(6번 표)
3. 기간 수익률의 기간을 별도로 되묻는 방식(T3)
4. 지표 4·5의 "보통 = default" 예외 (3번 2항)
